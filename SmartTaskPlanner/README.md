# Smart Task Planner

## Project Description

Smart Task Planner is a web-based application designed to help users organize, manage, and track their daily tasks efficiently. It provides a simple and user-friendly interface where users can add tasks, set priorities, assign due dates, and monitor their progress.

The application is developed using HTML, CSS, and JavaScript for the frontend, Python Flask for the backend, and SQLite for database storage. It helps users improve productivity, manage time effectively, and complete tasks in an organized manner.

## Objectives

- To organize daily tasks in one place.
- To set task priorities and due dates.
- To track pending and completed tasks.
- To search and filter tasks easily.
- To store task information in a database.

## Technologies Used

- **HTML:** Creates the website structure.
- **CSS:** Provides styling and responsive design.
- **JavaScript:** Handles user interactions and communicates with the backend.
- **Python Flask:** Manages server-side operations and APIs.
- **SQLite:** Stores task information.

## Main Features

1. Add new tasks with titles and descriptions.
2. Set task priorities as High, Medium, or Low.
3. Assign due dates to tasks.
4. Mark tasks as completed.
5. Search tasks by title or description.
6. Filter tasks by status and priority.
7. Delete tasks when they are no longer needed.
8. View total, pending, and completed task counts.

## How to Run the Project

1. Install Python on your computer.
2. Install Flask using `python -m pip install flask`.
3. Open the project folder in Command Prompt.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000` in your web browser.

## Conclusion

Smart Task Planner provides a convenient way to manage daily activities and monitor task completion. This project demonstrates how frontend technologies, a Python Flask backend, and an SQLite database can work together to create a functional web application.
