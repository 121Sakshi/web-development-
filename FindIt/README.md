# FindIt – Smart Lost and Found System


FindIt is a web-based application designed to help people find lost items and report items they have found. Users can submit details about lost or found belongings, including the item name, location, description, contact information, and an optional photo.

The website allows users to search for items by name or location and filter reports into Lost Items and Found Items. Its goal is to make it easier for people to reconnect with their missing belongings and return found items to their rightful owners.

## Main Features
- Report lost items.
- Report found items.
- Upload photos of items.
- Search items by name or location.
- Filter reports by Lost and Found categories.
- Store item reports in a database.
- Simple and user-friendly interface.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite

## Objective
The main objective of FindIt is to provide a simple digital platform that helps people report, search for, and recover lost belongings efficiently.
